# Idea del Proyecto:

La idea de este proyecto consiste en el diseño y desarrollo de un portfolio web personal como herramienta de presentación profesional, cuyo objetivo es mostrar de manera clara, atractiva y funcional los trabajos, habilidades y proceso creativo del autor. El sitio web estará pensado no solo como un espacio expositivo, sino también como una extensión de la identidad visual y personal, cuidando la coherencia estética, la usabilidad y la experiencia del usuario. A través de una estructura intuitiva y un diseño responsive, el portfolio permitirá comunicar el enfoque profesional, facilitar el contacto con potenciales clientes o empleadores y servir como soporte digital para la proyección laboral en el ámbito creativo.

# Stack tecnológico utilizado

- HTML5 para la estructura del sitio
- CSS3 para la maquetación y estilos
- JavaScript vanilla para la interacción
- Visual Studio Code para el desarrollo del proyecto
- GitHub Pages para el control de versiones y despliegue estático

# Guía de personalización

Este proyecto utiliza una arquitectura modular de CSS para facilitar la escalabilidad y la personalización.

# 1. CSS

1.1 assets/css/base.css
Contiene: Reset básico, variables iniciales y estilos globales aplicados al documento.

1.2 assets/css/components.css
Contiene: botones, tarjetas, bloques y elementos visuales comunes.

1.3 assets/css/index.css
Archivo “barrel”. Centraliza y agrupa todos los imports de los demás archivos CSS.
Su función es organizativa, asi que no puedes personalizarla.

Solo toca este archivo si necesitas añadir o eliminar un módulo CSS.

1.4 assets/css/layout.css
Contiene: reglas relacionadas con layout, grid, flexbox, espaciados estructurales, contenedores y distribución.

1.5 assets/css/navigation.css
Estilos exclusivos de la barra de navegación:

1.6 assets/css/theme.css
Núcleo del sistema visual del proyecto.

Tipografías fluidas (funciones clamp).

Espaciado responsivo.

Paleta de colores.

Variables de animación.

Familias tipográficas.

# 2. Imágenes y recursos

2.1 assets/icons/
Pequeño icono favicon representativo de la página web.

2.2 assets/images/
Contiene las imágenes del portfolio:
Puedes reemplazarlas actualizando la ruta desde index.html.

# 3. JavaScript

3.1 assets/js/main.js
Contiene:

Animaciones de scroll usando IntersectionObserver.

Smooth scroll profesional.

Resalte de la sección activa en el menú usando IntersectionObserver.

Animaciones Modals para las tarjetas de los proyectos.

# 4. HTML

4.1 404.html
Página de error personalizada para GitHub Pages.

4.2 index.html
Estructura total de todo el contenido de la página web: secciones, textos, imágenes, etc.
